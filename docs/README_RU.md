## Возможности

- **Многоязычный интерфейс**: локализует панели Powertools, основные меню Antigravity, диалоги разрешений, настройки и фреймы Swarm, не затрагивая текст диалогов и блоки кода.
- **Телеметрия контекста и скорости**: добавляет рядом с полем ввода кольцо контекста (с долей кэша, числом сжатий и шкалами планировщика и исполнителя Orchestrator) и индикатор скорости (`tok/s`, TTFT, время модели и инструментов, оценочная стоимость сессии), включая статистику субагентов.
- **Локальная панель расхода и запросов**: добавляет страницу `Powertools` в боковую панель с объединением данных десктоп-клиента и `agy` CLI — обзор расхода (тепловая карта за 53 недели, диаграммы токенов и затрат, таблица моделей), журнал запросов, отметки аномалий кэша, копирование ошибок в один клик, оценка квот и обновление официальных цен API.
- **Компактный вид и отчёты по этапам**: сохраняет размер шрифта клиента, уменьшая межстрочный интервал и отступы блоков; выводит краткие обновления статуса во время многошаговых вызовов инструментов и сворачивает их в заголовок длительности после завершения.
- **Ветвление диалогов и редактирование сообщений**: создание ветки нового чата из любого ответа или меню диалога с полным сохранением истории (включая диалоги с субагентами), а также редактирование отправленного сообщения на месте через нативное поле ввода Antigravity.
- **Переключение нескольких аккаунтов (выкл. по умолчанию)**: использует Диспетчер учётных данных Windows, Связку ключей macOS или Linux Secret Service для изолированного хранения аккаунтов Google без открытых токенов; позволяет проверять 5-часовые и недельные квоты, переключаться из боковой панели и включать автопереключение при исчерпании квоты.
- **Прокси приложения без TUN (выкл. по умолчанию)**: передаёт аргументы и переменные прокси только процессу Antigravity при перезапуске, поддерживает проверку HTTP CONNECT / SOCKS5, уведомление при холодном старте и опцию `GODEBUG=http2client=0` для снижения обрывов `EOF`.
- **Поддержка SSH Remote и WSL2**: считывает метрики удалённых сессий, субагентов и обзора в окнах `SSH` через локальный OpenSSH без установки чего-либо на сервер; поддерживает Windows Antigravity с бэкендом WSL2 в режимах сети NAT и Mirrored, гибридное хранение учётных данных и делегирование перезапуска.
- **Контекстное меню файлов и утилиты**: по правому клику на ссылки файлов или дерево файлов доступны прикрепление к чату, открытие в приложении, показ в папке, копирование файла или пути (включая сетевые пути LAN NAS / SMB в Windows); также добавлены сворачиваемые блоки «Ход выполнения» и «Квота» в панели «Обзор», счётчик непрочитанного в заголовке окна, опциональный контур квоты и тонирование пузырей пользователя.

## Бесполезные функции (но красивые)

<p align="center">
  <img src="./images/card-border-beam.webp" alt="Предпросмотр световой рамки поля ввода при работе" width="100%" />
</p>

- **Световая рамка поля ввода при работе (выкл. по умолчанию)**: вдохновлена [border-beam-ios](https://github.com/ismnoiet/border-beam-ios) и реализована на лёгком WebGL-шейдере SDF для скруглённого прямоугольника. Пока агент работает, по периметру поля ввода с постоянной скоростью движется световой шлейф с мягким внутренним свечением, а после завершения ответа плавно затухает до нулевой нагрузки на CPU и GPU. Корректно переключается с контуром квоты при одновременном включении, предлагает 6 палитр (`Gemini`, `Aurora`, `Colorful`, `Neon`, `Accent`, `Quota`) и кнопку **Проверить предпросмотр** в настройках.

## Установка

> Требования: установленный Antigravity, запущенный хотя бы один раз. Использует локальный Node.js `>= 22.13` либо встроенный `agy-node` из состава Antigravity. Не требует `npm install` и прав администратора.

### Вариант 1: Установка через агента (рекомендуется)

Отправьте этот запрос в Antigravity или другой локальный coding-агент:

> Please install Agy Powertools from https://github.com/WhiteBr1ck/agy-powertools . Read README_EN.md and docs/INSTALL_AGENT.md first, and run the unified installer provided by the project using local Node.js or Antigravity's bundled runtime. Keep all other plugins, account settings, and chat history intact, and do not force-close the running client. Verify the installed version afterward and remind me if a client restart is needed.

Подробности см. в [Руководстве по установке через агента](./INSTALL_AGENT.md).

### Вариант 2: Из командной строки

Скачайте и распакуйте последний ZIP-архив со страницы [Releases](https://github.com/WhiteBr1ck/agy-powertools/releases) (или клонируйте репозиторий), затем выполните:

```powershell
# Windows (PowerShell)
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

```sh
# macOS / Linux / WSL2
sh ./install.sh
```

Повторная установка сохраняет ваши настройки и не закрывает запущенный Antigravity принудительно. Перезапустите Antigravity после завершения текущей задачи — пункт **Powertools** появится в левой боковой панели. На macOS дополнительный ярлык `.app` не создаётся: при открытии стандартного `Antigravity.app` клиент при необходимости один раз автоматически перезапустится с флагом отладки (со встроенной защитой от циклов и переключателем на ручной перезапуск в разделе Настройки или Плагины -> Powertools).

### Обновление и удаление

- **Обновление внутри приложения**: откройте **Powertools -> Настройки -> О плагине -> Проверить обновления** и нажмите **Установить обновление**. Архивы проверяются по SHA-256 и автоматически откатываются при ошибке запуска.
- **Удаление**: выполните `powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1` (Windows) или `sh ./uninstall.sh` (macOS / Linux / WSL2). Добавьте флаг `--keep-settings`, чтобы сохранить конфигурацию. История диалогов, аккаунты и другие плагины не затрагиваются.

### v2.16.6
- **Исправлена некликабельность строк диалогов в боковой панели при включённой световой рамке**: убрано переопределение `position: relative` у дочернего элемента, которое ломало ссылку строки `position: absolute; inset: 0`, восстановив клики по всей строке и кнопкам при наведении.
- **Доработаны слои и плавное затухание нижней подсветки в боковой панели**: слой подсветки с `pointer-events: none` поднят выше панели действий при наведении (`z-index: 20`), устранена резкая обрезка за иконками, добавлены маски плавного входа и выхода по краям (`.agy-sb-fade`).

### v2.16.5
- **Исправлена точность недельной квоты и статистики использования (#63)**:
  - `lib/quota.mjs`: предотвращает перезапись валидных контрольных точек обнулёнными или откатившимися сканированиями.
  - `lib/dashboard.mjs`: сопоставляет каждый запрос с границами недельного окна собственного пула квот (Gemini / Claude / Argon) вместо единой самой ранней метки времени.
  - `lib/analytics.mjs`: сохраняет атомарный архив расхода по профилям (хранение 90 дней, до 20 000 запросов), чтобы недельные итоги не падали при очистке старых файлов `.db`.
- **Упрощение интерфейса и переводы настроек**:
  - Убраны дублирующиеся всплывающие подсказки на кольце контекста, кольце субагентов и кнопке скорости (с сохранением `aria-label`), чтобы они не перекрывали открытые поповеры.
  - Упрощена карточка стоимости в «Обзоре» и заголовок стоимости в таблице моделей: оставлены итоговая и средняя стоимость на запрос.
  - Добавлены 5 недостающих переводов настроек Antigravity 2.35.2.
- **Изменения от сообщества**:
  - **Выбор локального шрифта и начертания (PR #78, `@awei84`)**: выбор семейства и доступных начертаний с извлечением локализованных имён шрифтов OpenType, исключая иконочные шрифты и терминал xterm.
  - **Световая рамка активных диалогов и закреплённая группа «Выполняются» (PR #76, `@whitzard0421`)**: обе функции отключены по умолчанию; чистая CSS-подсветка нижней кромки без WebGL с поддержкой `prefers-reduced-motion`.
  - **Перетаскивание папок на боковую панель для создания проектов (PR #73, `@niuanhua-ydy`)**: создание и открытие проектов с проверкой каталогов/симлинков и изоляцией окон SSH Remote.

### v2.16.4
